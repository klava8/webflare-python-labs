# Простой калькулятор

Учебный проект на Python. Показывает сумму и произведение двух чисел.

## Файлы

- `addition.py` - функция сложения.
- `multiplication.py` - функция умножения.
- `main.py` - ввод данных и вывод результатов.

## Запуск

Нужен Python 3. Дополнительные библиотеки для запуска не требуются.

```bash
python main.py
```

Введите два числа с точкой в качестве десятичного разделителя.
Для 2 и 3 программа выводит сумму 5.0 и произведение 6.0.
Неверный ввод вызывает сообщение об ошибке.

## Проверка оформления

После установки инструментов разработки:

```bash
python -m pip install -r requirements-dev.txt
python -m pycodestyle .
```
